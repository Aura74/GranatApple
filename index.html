Animation Technology

Rive Animationer

Rive är tekniken som pomegranate.health använder för sina animerade telefoner. Interaktiva vektoranimationer som kan reagera på hover, klick och scroll.

Skapa egna på rive.app

Vehicles

Animerade fordon med vädereffekter

Off-Road Car

Terrängbil i rörelse

Juice

Animerad illustration

Hur skapar man Rive-animationer?

1
Skapa konto

Gå till rive.app - gratis att använda

2
Designa i editorn

Rita former, lägg till bones, skapa animationer

3
Exportera .riv

Ladda ner din animation som .riv-fil

4
Lägg till på webben

Använd @rive-app/canvas för att visa den

Kod-exempel:

<script src="https://unpkg.com/@rive-app/canvas"></script>
<canvas id="rive-canvas"></canvas>
<script>
  new rive.Rive({
    src: "animation.riv",
    canvas: document.getElementById("rive-canvas"),
    autoplay: true
  });
</script>

Alternativ: Lottie

Om du redan använder After Effects kan Lottie vara enklare. Exportera animationer som JSON.

Chart Library #1

Chart.js

Det enklaste biblioteket att börja med. Perfekt för stapel-, linje- och cirkeldiagram. Endast ~60KB och MIT-licensierat.

chartjs.org

Fördelar

  • Enkel att komma igång
  • Responsiv och animerad
  • 8 inbyggda diagramtyper
  • Bra dokumentation

Användning

<script src="chart.js"></script>
Chart Library #2

D3.js

Det mest kraftfulla visualiseringsbiblioteket. Fullständig kontroll över varje pixel. Används av New York Times, BBC och NASA.

d3js.org

Fördelar

  • Oändlig flexibilitet
  • SVG-baserat
  • Kraftfulla övergångar
  • Databindning

Nackdelar

  • Brant inlärningskurva
  • Mer kod krävs
Chart Library #3

ApexCharts

Moderna, interaktiva grafer med minimal konfiguration. Snyggast "out of the box" med zoom, pan och export inbyggt.

apexcharts.com

Fördelar

  • Professionellt utseende
  • Interaktiv (zoom, pan)
  • Exportera till PNG/SVG
  • Dark mode inbyggt

Användning

<script src="apexcharts.js"></script>
Chart Library #4

Frappe Charts

Lättviktigt (~25KB) med GitHub-inspirerad design. Perfekt för dashboards och enkla visualiseringar.

frappe.io/charts

Fördelar

  • Minsta filstorleken
  • Heatmaps (GitHub-stil)
  • Inga beroenden
  • MIT-licens

Perfekt för

  • Enkla dashboards
  • Prestandakritiska appar
