Hur skapar man Rive-animationer?

  1. 1
    Skapa konto

    Gå till rive.app – gratis att använda

  2. 2
    Designa i editorn

    Rita former, lägg till bones, skapa animationer

  3. 3
    Exportera .riv

    Ladda ner din animation som .riv-fil

  4. 4
    Lägg till på webben

    Använd @rive-app/canvas för att visa den

Kodexempel

<script src="https://cdn.jsdelivr.net/npm/@rive-app/canvas@2.42.1/rive.min.js"></script>
<canvas id="rive-canvas"></canvas>
<script>
  new rive.Rive({
    src: "animation.riv",
    canvas: document.getElementById("rive-canvas"),
    autoplay: true
  });
</script>

Chart Library #1

Chart.js

Det enklaste biblioteket att börja med. Perfekt för stapel-, linje- och cirkeldiagram. Endast ~60 KB och MIT-licensierat.

chartjs.org

Fördelar

  • Enkel att komma igång
  • Responsiv och animerad
  • 8 inbyggda diagramtyper
  • Bra dokumentation

Användning

<script src="chart.umd.js"></script>
Chart Library #2

D3.js

Det mest kraftfulla visualiseringsbiblioteket. Fullständig kontroll över varje pixel. Används av New York Times, BBC och NASA.

d3js.org

Fördelar

  • Oändlig flexibilitet
  • SVG-baserat
  • Kraftfulla övergångar
  • Databindning

Nackdelar

  • Brant inlärningskurva
  • Mer kod krävs
Chart Library #3

ApexCharts

Moderna, interaktiva grafer med minimal konfiguration. Snyggast "out of the box" med zoom, pan och export inbyggt.

apexcharts.com

Fördelar

  • Professionellt utseende
  • Interaktiv (zoom, pan)
  • Exportera till PNG/SVG
  • Dark mode inbyggt

Användning

<script src="apexcharts.min.js"></script>
Chart Library #4

Frappe Charts

Lättviktigt (~25 KB) med GitHub-inspirerad design. Perfekt för dashboards och enkla visualiseringar.

frappe.io/charts

Fördelar

  • Minsta filstorleken
  • Heatmaps (GitHub-stil)
  • Inga beroenden
  • MIT-licens

Perfekt för

  • Enkla dashboards
  • Prestandakritiska appar
